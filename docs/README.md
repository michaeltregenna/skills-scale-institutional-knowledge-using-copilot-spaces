# OctoAcme Project Management Docs

## Overview

OctoAcme Project Management Processes is a lightweight, customer-first methodology for delivering product features, services, and integrations. Built on principles of iterative delivery, clear ownership, and data-informed decisions, these processes guide teams through the entire project lifecycle from initiation through retrospectives.

Our approach emphasizes:
- **Delivering customer value** through regular feedback and iteration
- **Transparency and alignment** across all stakeholders
- **Shared ownership** with named Project Managers and Product Leads accountable for outcomes
- **Evidence-based decisions** grounded in metrics and user feedback
- **Psychological safety** that encourages learning and continuous improvement

## Project Lifecycle

OctoAcme follows a five-phase project lifecycle:

1. **Initiation** – Validate business need, define success metrics, and align stakeholders
2. **Planning** – Break work into shippable increments and create an actionable delivery plan
3. **Execution** – Build, test, and deliver with daily standups and continuous quality checks
4. **Release** – Deploy to production with confidence and communicate changes to stakeholders
5. **Retrospective & Improvement** – Capture learnings and iterate on processes

## Core Values

- **Customer-first**: Prioritize customer value and usability
- **Iterative delivery**: Deliver small, testable increments
- **Clear ownership**: Named Project Managers and Product Leads own outcomes
- **Data-informed**: Measure impact and iterate based on evidence
- **Psychological safety**: Encourage feedback, learning, and continuous improvement
